## Question and hypothesis

Can `black-forest-labs/FLUX.2-klein-base-4B` load, perform image editing, complete a tiny paired edit-LoRA training cycle, save an adapter, and reload it for inference on the Supervisor's free Kaggle GPU? Can the Base-trained adapter execute with `black-forest-labs/FLUX.2-klein-4B` distilled inference?

The hypothesis is feasibility under documented low-memory settings. [BFL training guidance](https://docs.bfl.ai/flux_2/flux2_klein_training) lists an NVIDIA GPU with 12 GB VRAM and 32 GB RAM as its Klein 4B Base training minimum, while [BFL's worked LoRA guide](https://huggingface.co/blog/black-forest-labs/flux-2-klein-lora) describes a run under 24 GB VRAM on an RTX 4090. Neither establishes performance on this Kaggle account. The [Base model card](https://huggingface.co/black-forest-labs/FLUX.2-klein-base-4B) verifies the model ID, image-edit capability, and Apache-2.0 license. [NVIDIA's CUDA guide](https://docs.nvidia.com/cuda/cuda-programming-guide/05-appendices/mathematical-functions.html) places native BF16 at compute capability 8.0+, so a runtime with capability 7.5 must use an evidence-backed non-BF16 path.

Source: [Kaggle smoke-test script](../../notebooks/exp001_flux2_klein_kaggle_smoke.py). It does not bundle model weights or real photos.

In an authenticated Kaggle GPU notebook, enable internet and GPU, make the script available as a notebook input or in `/kaggle/working`, and run:

The first command audits without downloads. The second starts with another audit and stops before model download if GPU or scratch checks fail. [Kaggle's notebook documentation](https://www.kaggle.com/docs/notebooks) describes `/kaggle/working` as saved output and additional scratch as session-only, but the script measures actual disks and mounts before choosing a cache.

The runtime pins the *observed* commit in `dependencies.json`; it is not pre-pinned in the source and may change between future sessions.

- Base edit uses seed 1977, 512×512, 20 inference steps, guidance 4.0, and the prompt in the script. Distilled test, only if scratch permits, uses four steps and guidance 1.0.
