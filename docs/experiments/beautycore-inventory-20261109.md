## Implementation

The existing inventory and ledger are retained. Migration 0014 widens quantity storage to exact numeric without changing legacy values, adds optional metadata/suppliers/service requirements/transaction snapshots/consumption records and installs guarded stock/completion functions. There are no product seeds or historical consumption deductions. Legacy counts are not guessed to be bottles, grams or milliliters. Metadata purchase costs are distinct from the old selling-price field.

The administrator workspace includes product management, optional images, suppliers, receipts, stock-out/disposal/corrections, physical-count adjustments, service supply planning, low/out/expiry attention, recent records, filters and actual-ledger reports. The unsaved reference catalog is grouped by the eight requested salon categories. Staff have a supplies/requirements view and the existing appointment completion form gains stock reporting. The administrator layout displays inventory attention notifications linked to the workspace.

Default completion now asks only for products that were used up and their quantities. An empty list is allowed; other products are not deducted. Database IDs and stored units identify reported products, and server-owned metadata supplies costs. Equipment is excluded. An administrator may deliberately enable configured-consumption mode to prefill all service estimates, retaining the original requested automatic-requirements workflow. This optional mode validates actual quantity deviations with reasons. The configured-database installation defaults to reported-only mode; reinstalling preserves a subsequently chosen policy.

Both modes use one completion transaction, sorted product locks, immutable audit rows, retry-safe completion and nonnegative stock. Default shortages block the whole completion; the optional consume-available policy stores the shortfall for review. Later authorized corrections append linked movements and reconcile net quantities without rewriting original consumption. Booking/start/cancellation/no-show do not consume inventory.
